# JI XR GAME JAM创意编程及交互设计大赛圆满落幕

![](images/img-1.gif)

  

  

  

5月24日，由唐君远学生创新创业中心指导、JI XR Club主办的创意编程及交互设计大赛作品展暨决赛在上海交通大学密西根学院龙宾楼举行。唐君远学生创新创业中心主任马澄斌，密西根学院助理教授Christopher Linforth，中心专员肖建荣等出席活动颁奖典礼。这场持续两个月的跨学科创意马拉松，汇聚了来自密西根学院、设计学院、计算机学院、外国语学院等多领域的青年创新力量，大赛以“平衡 Balance”为主题，18个创作团队以代码为笔、数字为墨，在虚拟和现实交汇处勾勒出科技与人文交织的智慧图卷，共同解构“平衡”的多种可能。

  

  

  

![](images/img-2.jpg)

创意编程与交互设计大赛合影

  

活动现场，各参赛团队通过专业讲解向来宾全面展示游戏创意，从核心玩法到设计理念进行多维度阐释，并同步开放作品体验环节，使观众在沉浸式互动中深入理解作品内涵。体验过程中，创作者与玩家围绕游戏细节展开即时交流，形成创意理念与用户反馈的双向互动场景。为保障决赛投票环节的公平公正，活动采用实名注册投票机制，观众通过扫码完成身份认证后获得专属投票资格，可依据现场体验感受为心仪团队投票。

创作团队为观众讲解设计理念

  

《After dusk》作品团队的原创人物设计令人眼前一亮。这些角色背后蕴含着一个探讨理想与现实的故事，通过游戏中的平衡与矛盾，让玩家在体验中深刻共鸣---如何在成长道路上坚守自我。《嘉靖浮沉志》则凭借高质量的剧情设计，带领玩家在嘉靖年间的乱世中不断权衡抉择，寻求动态平衡。作品巧妙运用AI生成的高质量场景插画，使历史情境栩栩如生，让玩家自然沉浸其中。这种“创作-体验-反馈”的闭环设计，让观众从旁观者变为共创者，深刻诠释平衡的动态本质。

现场同学体验作品的不同创意与玩法

  

经过激烈角逐，《The Last Librarian》作品团队凭借新颖的游戏机制和富有创意的叙事摘得桂冠；《Balanced Heart》作品团队呈现了完成度极高的卡牌游戏，其精心设计的原创卡牌系统与缜密的编程逻辑，与充满奇幻色彩的中世纪战斗游戏《Sword of Avalon》作品团队共同荣获亚军。

  

![](images/img-11.jpg)

马澄斌为大赛闭幕致辞

  

马澄斌在闭幕致辞中表示课堂上的理论知识仅是创新的起点，唯有将知识转化为动手实践，在项目打磨中锤炼技能，同学们才能实现全方位成长。他鼓励大家保持这份探索热情，未来可以在更多更硬核的学科交叉领域持续深耕，让学科融合的智慧火花在实践中迸发，为科技发展注入青春动能。

  

真正的创新往往诞生于不同思维的碰撞之中，冀望未来同学们在创新实践中创造出更多兼具技术深度与思想厚度的作品。随着大赛帷幕落下，这个关于“平衡”的开放式命题仍在延续，我们向所有心怀热忱的探索者发出邀约，期待更多伙伴加入这场没有终点的创新之旅——或许下一个解构“平衡”的创意，就诞生于你的指尖。
