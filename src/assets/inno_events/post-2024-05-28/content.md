# 荣誉 | 密院学子喜获两项美国大学生数学建模竞赛特等奖！

![](images/img-1.gif)

  

  

  

  

  

  

  

  

  

  

  

  

  

  

  

  

近日，2024年美国大学生数学建模竞赛（英文简称“MCM/ICM”，中文简称“美赛”）成绩揭晓，由上海交通大学密西根学院学生领衔或参与的多支队伍在与全球众多高校学子的竞争中脱颖而出，摘取多个奖项。其中，密西根学院大二学生杨瑞凯、时涵天、吴宇通团队荣获特等奖（Outstanding Winner），密西根学院大三学生李健恺荣获特等奖（Outstanding Winner）及Vilfredo Pareto Award冠名特别奖项，3支队伍荣获特等奖提名奖（Finalist Winners），11支队伍荣获一等奖（Meritorious Winners），5支队伍荣获二等奖（Honorable Mentions），12支队伍荣获三等奖（Successful Participants），祝贺他们！

  

  

  

  

  

  

  

  

  

  

  

  

  

  

  

![](images/img-2.png)

![](images/img-3.png)

![](images/img-4.png)

美赛由美国数学及其应用联合会（COMAP）主办，被公认为全球最具影响力的数学建模比赛，赛题内容涉及经济、管理、环境、资源、生态、医学、安全等众多领域。比赛队伍以三人小组为单位，要求在四天内完成针对某一现实问题的建模及论文撰写，考验参赛选手研究问题、解决方案的能力及团队合作精神。

  

![](images/img-5.png)

特等奖杨瑞凯、时涵天、吴宇通团队作品

  

![](images/img-6.png)

![](images/img-7.png)特等奖李健恺团队作品

  

据统计，今年竞赛共吸引来自美国、加拿大、英国等20多个国家与地区的28912支队伍，其中包括康奈尔大学、杜克大学、哥伦比亚大学、卡内基梅隆大学以及清华大学、上海交通大学等国内外顶尖高校的学子。自2012年密西根学院科技与创新协会组织学院学生参赛以来，参赛团队表现出色，目前已累计获得特等奖5项、特等奖提名18项、一等奖43项，二等奖104项。

  

![](images/img-8.jpg)

![](images/img-9.jpg)

特等奖团队奖状

  

本次特等奖获奖队员、密院大二学生时涵天表示参加美赛让他深刻体会到团队合作的重要性，通过明确分工、高效沟通、快速应变，要确保每个人的优势得到最大化的发挥，“在比赛中我们不仅收获了知识和技能，更结交了志同道合的朋友。这不仅是一次能力的提升，更是一次难忘的成长旅程。这些经历不仅提升了我们的专业知识和综合能力，也让我们在未来的发展中受益匪浅。”

  

特等奖及Vilfredo Pareto Award冠名特别奖项获奖队员、密院大三学生李健恺在比赛中主要负责论文排版与写作，他表示在比赛过程中需要实时跟进建模工作，了解模型的详细过程和思路，有助于在写作时更好地解释和呈现研究成果，并在有限的时间内，通过任务的合理规划以及工具的使用，不断斟酌完善论文结构和内容，以提高论文整体质量。
