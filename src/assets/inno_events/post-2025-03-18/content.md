# 上海交通大学第十五届“黎明杯”新生机械创意大赛正式开幕

![](images/img-1.gif)

  

3月16日，上海交通大学第十五届“黎明杯”新生机械创意大赛开幕仪式在龙宾楼300报告厅举行。校团委副书记汤翔鹰，溥渊未来技术学院党委副书记韩海波，材料科学与工程学院团学工作负责人宋逸思，电子信息与电气工程学院团委辅导员夏一凡，密西根学院党委副书记王冲、副院长申岩峰、唐君远学生创新创业中心主任马澄斌出席活动。活动由辅导员王子怡主持。

本届比赛吸引了来自密西根学院、医学院、机械与动力工程学院的学生组成41支队伍报名。

  

  

  

**开场致辞**

  

  

汤翔鹰作开场致辞。他强调，在全球新一轮科技革命和产业革命下，科技创新正在成为高质量发展的推动引擎，交大学子肩负着实现高水平科技自立自强的历史使命，“黎明杯”正是同学们开启创新旅程的重要起点之一。汤翔鹰对同学们提出了三点希望：一是勇于跨界合作，勇于打破学科壁垒，利用学科交叉突破传统行业；二是注重实践探索，磨炼实干能力，将创意变为现实，做青年实干家；三是敢于突破常规，追求颠覆性创新，敢于跳出思维定式，勇攀创新高峰。

![](images/img-2.png)

汤翔鹰为活动作开场致辞

  

  

  

**赛事规则介绍**

  

  

赛事委员会游戏组张凌玮、赛制组徐蘇怡介绍了本次机械赛的游戏规则与赛制安排。张凌玮介绍了本次赛事的场地布局和规则概述，结合赛道图片介绍五大关卡与一个独立比赛的游戏规则与计分方式。徐蘇怡介绍了赛程时间安排，对赛制和淘汰规则进行阐释。

![](images/img-3.png)

  

![](images/img-4.png)

张凌玮、徐蘇怡介绍游戏规则与赛制安排

  

  

  

**样机展示与讲解**

  

  

样机组罗弘毅向选手们展示样机，讲解了样机的基础材料、整车设计、电控组件等细节，现场播放了样机功能展示视频。样机组施为一现场演示了样机功能，并针对大赛的机械设计提供了建议。

  

  

  

**裁判组宣誓**

  

  

随后，由耿子聪同学代表赛事委员会裁判组进行宣誓，承诺将严格遵守规则纪律，严格遵行裁判职责，文明裁判、严肃认真、不徇私情、以公办事，圆满完成各项赛事。

  

![](images/img-5.png)

耿子聪代表裁判组宣誓

  

  

  

**总结致辞**

  

  

![](images/img-6.png)

王冲为活动作总结致辞

王冲、马澄斌进行开幕仪式总结致辞。王冲用“感谢”、“珍惜”、“勇敢”三个关键词进行总结。他首先回顾了新生机械赛的创办历史和发展历程，表达了对学校、兄弟院系、办赛学生和浙江黎明的感谢。他强调，师生校企薪火相传才让机械赛延绵至今。王冲表示，要珍惜平台、珍惜机会，比赛更重要的是过程中的酸甜苦辣及收获的友谊与成长。王冲希望同学们能勇敢尝试，也要勇敢面对失败，比赛结果远不如其中得到的锻炼更有意义。

  

![](images/img-7.png)

马澄斌为活动作总结致辞

马澄斌鼓励同学们多尝试，学会将知识融会贯通。马澄斌强调了实践和总结的重要性，他表示凡事越做越简单，越想越复杂，越拖越想放弃。要学会总结，即便是失败，只要能够系统性回顾都是巨大的成功。

上海交通大学“黎明杯”新生机械创意大赛已成功举办14届，是一场思维的碰撞、实践的历练。密西根学院将继续坚持以学生为中心，以打造集多样创新资源于一体的国际化协同创新平台为己任，为学生的科技创新厚植一片沃土。
